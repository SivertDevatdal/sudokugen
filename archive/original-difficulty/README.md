# Original-difficulty puzzles (archived 2026-10-27)

These are puzzles generated with the `original` difficulty setting
(MIDDELS = medium, VANSKELIG = hard) for days after the paper switched to
easier puzzles and to printing each day's own solutions:

- 2026-10-28 through 2026-12-08 had already been generated when the
  switch was made.
- 2026-12-09 through 2027-01-01 were added by the monthly workflow on
  2026-11-01, which still ran the old settings on `main`.

They were replaced before publication and are not used in the paper.

- `puzzles/` — the dated JSON files, unchanged.
- `pdfs/` — the column PDFs as they were, which follow the old convention
  of printing the *previous* publishing day's solutions.

To go back to the original difficulty, see "Difficulty" in the main
README. To reuse these exact puzzles, copy the JSON files back into
`puzzles/` (replacing the newer ones) and delete the matching PDFs in
`pdfs/` so kukoku re-renders them with same-day solutions.
