# Original-difficulty puzzles (archived 2026-10-27)

These are the puzzles that had already been generated for 2026-10-28
through 2026-12-08 with the `original` difficulty setting (MIDDELS =
medium, VANSKELIG = hard) when the paper switched to the `easier` setting
and to printing each day's own solutions. They were replaced before
publication and are not used in the paper.

- `puzzles/` — the dated JSON files, unchanged.
- `pdfs/` — the column PDFs as they were, which follow the old convention
  of printing the *previous* publishing day's solutions.

To go back to the original difficulty, see "Difficulty" in the main
README. To reuse these exact puzzles, copy the JSON files back into
`puzzles/` (replacing the newer ones) and delete the matching PDFs in
`pdfs/` so kukoku re-renders them with same-day solutions.
