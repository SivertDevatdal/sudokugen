# Easier-difficulty puzzles (archived 2026-10-28)

The puzzles generated for 2026-10-29 through 2026-11-27 with the `easier`
difficulty setting (MIDDELS = easy, VANSKELIG = medium), as they were
before VANSKELIG was made a little harder with the `between` setting.

- `puzzles/` — the dated JSON files, unchanged.
- `pdfs/` — the column PDFs as they were (same-day solutions, upside down).

Only the VANSKELIG puzzles were replaced: the MIDDELS puzzles in these
files are the same ones that are in `puzzles/`.

To go back to the `easier` VANSKELIG, see "Difficulty" in the main README.
To reuse these exact puzzles, copy the JSON and PDF files back into
`puzzles/` and `pdfs/`, replacing the newer ones.
